Лабораторные работы №1–5

В этом файле собраны только решения варианта 2.
Каждое задание запускается отдельно: скопируйте содержимое одного блока
между ```csharp и ``` в Program.cs консольного проекта .NET 8.
Сами ограничители копировать не нужно.

Каждое входное значение вводится отдельной строкой, как в исходнике.
Приглашения ко вводу сохранены. Используются понятные имена переменных
и исходные учебные алгоритмы.

Вещественные числа вводятся с точкой. Размер массива или матрицы
перед элементами вводить не нужно: размер задан в коде.
В суммах и произведениях, где возможно переполнение int, используется
long; для факториала и Фибоначчи — BigInteger. Подробнее — в коде
и примечаниях к заданиям. Ввод символа в 2.3 работает через stdin.

ЛАБОРАТОРНАЯ №1 — ЗАДАНИЕ №10
Калькулятор
ВАРИАНТ 2
========================================================================
Ввод: два вещественных числа, затем знак +, -, * или /.
Примечание: Порядок ввода: a b знак, а не a знак b. Неизвестная операция, как в исходнике, ничего не выводит.

```csharp
using System;
using System.Globalization;

class Program
{
    static void Main()
    {
        CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;
        double leftOperand = double.Parse(Console.ReadLine());
        double rightOperand = double.Parse(Console.ReadLine());
        string operation = Console.ReadLine();
        switch (operation)
        {
            case "+":
                Console.WriteLine(leftOperand + rightOperand);
                break;
            case "-":
                Console.WriteLine(leftOperand - rightOperand);
                break;
            case "*":
                Console.WriteLine(leftOperand * rightOperand);
                break;
            case "/":
                if (rightOperand != 0)
                {
                    Console.WriteLine(leftOperand / rightOperand);
                }
                else
                {
                    Console.WriteLine("Нөлге бөлуге болмайды!");
                }

                break;
        }
    }
}
```

Ввод значений и вывод их типов
ВАРИАНТ 2
========================================================================
Ввод: целое, вещественное, один непробельный символ; в варианте 2 — по строке на значение.
Примечание: Console.ReadKey заменён чтением stdin: программа работает при перенаправлении ввода. Эхо клавиши и пустая строка перед результатом убраны. В варианте 2 символ — первый символ третьей строки (может быть пробелом).

```csharp
using System;
using System.Globalization;

class Program
{
    static void Main()
    {
        CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;
        int integerValue = int.Parse(Console.ReadLine());
        double realValue = double.Parse(Console.ReadLine());
        char character = Console.ReadLine()[0];
        Console.WriteLine($"{integerValue} ({integerValue.GetType()}), {realValue} ({realValue.GetType()}), {character} ({character.GetType()})");
    }
}
```

Ввод: ровно девять целых чисел, по строкам матрицы.
Примечание: Сравниваются только суммы строк, столбцов и диагоналей. Различность элементов и набор чисел 1–9 не проверяются, как в исходнике.

```csharp

using System.Globalization;

class Program
{
    static void Main()
    {
        CultureInfo.CurrentCulture = CultureInfo.InvariantCulture;
        int[, ] matrix = new int[3, 3];
        for (int row = 0; row < 3; row++)
        {
            for (int column = 0; column < 3; column++)
            {
                matrix[row, column] = int.Parse(Console.ReadLine());
            }
        }

        long expectedSum = 0;
        for (int column = 0; column < 3; column++)
        {
            expectedSum += matrix[0, column];
        }

        bool isMagic = true;
        for (int row = 0; row < 3; row++)
        {
            long lineSum = 0;
            for (int column = 0; column < 3; column++)
            {
                lineSum += matrix[row, column];
            }

            if (lineSum != expectedSum)
            {
                isMagic = false;
            }
        }

        for (int column = 0; column < 3; column++)
        {

            {

            }

        {
            mainDiagonalSum += matrix[row, row];
            secondaryDiagonalSum += matrix[row, 2 - row];

        {

        }

            Console.WriteLine("Magic square");
```
