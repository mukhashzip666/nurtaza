# CodeFlow

Локальное расширение Chrome Manifest V3. Оно выбирает одну из пяти лабораторных, одно из 71 заданий и вводит C# код в редакторе сайта AI Institute. Интерфейс открывается как обычная панель под значком расширения в Chrome, а на сайте доступна мини-панель сверху. Код не отправляется на проверку автоматически.

## Установка

Откройте `chrome://extensions`, включите «Режим разработчика» и нажмите «Загрузить распакованное расширение». Выберите папку `codeflow` с `manifest.json` либо её родительскую папку «Новая папка 6», где также есть `manifest.json`. npm и сборка для установки не нужны.

## Как добавляются решения

Решения хранятся **только в обычных TXT файлах** в `solutions/`. Файл для лабораторной №1, задания №1: `solutions/lab1/task1.txt`. Для лабораторной №3, задания №15: `solutions/lab3/task15.txt`. Все 71 файл заполнены присланными решениями «Вариант 2 — читаемое решение на основе исходника» для .NET 8.

Каждое входное значение вводится отдельной строкой, вещественные числа — с точкой. Приглашения ко вводу сохранены. Порядок ввода описан в общем файле `Все_решения_CodeFlow.txt`. Размеры массивов и матриц заданы в коде. Каждое решение — отдельная программа со своими вспомогательными методами.

Пользователь присылает C# код в чат по порядку, а ассистент сохраняет его в нужный файл проекта. Код можно также вставить в этот файл вручную обычным текстом: переносы строк и кавычки записываются как в C#. Если файл пуст, панель показывает «Решение пока отсутствует».

После изменения файла нажмите «Обновить» у CodeFlow в `chrome://extensions` и вновь откройте панель CodeFlow. Расширение считает непустой TXT файл доступным решением. Файл `.txt` может содержать C# код; расширение печатает текст файла и не исполняет его. Длина решения — до 100 000 символов UTF-16.

## Использование

1. Откройте сайт AI Institute, нужную лабораторную и задание.
2. Мини-панель CodeFlow появляется сверху справа. Зажмите её заголовок и перетащите в удобное место; положение сохранится после обновления страницы. Выберите ту же лабораторную и задание. Скорость можно выбрать там же или в обычной панели под значком расширения. По умолчанию выбрано «Очень быстро» — 10 мс между символами; отдельно доступна мгновенная вставка всего кода одним действием.
3. Нажмите на редактор кода, затем «Печать» в мини-панели. Кнопка «Стоп» останавливает печать; обычная панель также позволяет поставить её на паузу.
4. После завершения CodeFlow сам выбирает следующее задание (после последнего в лабораторной — первое в следующей). Страница сайта не переключается. Откройте следующее задание на сайте и снова нажмите «Печать».

Если страница задания уже была открыта при обновлении расширения, CodeFlow добавляет мини-панель в неё без перезагрузки сайта. При необходимости нажмите значок CodeFlow в Chrome: открытие обычной панели также восстанавливает мини-панель на открытых вкладках AI Institute.

Уже запущенная печать остаётся привязанной к вкладке, где она началась.

При запуске весь старый код в выбранном редакторе заменяется новым без ручного Ctrl+A. Если номер открытого задания виден на сайте и отличается от выбранного в CodeFlow, мини-панель не начнёт печать. Стоп оставляет уже введённые символы. После завершения проверьте код и отправьте задание самостоятельно.

## Файлы проекта

```text
Новая папка 6/
├── manifest.json
├── README.md
└── codeflow/
    ├── manifest.json
    ├── popup/                  интерфейс расширения
    ├── background/             service worker
    ├── content/                печать и адаптеры редакторов
    ├── lib/                    библиотека и проверка заданий
    ├── solutions/
    │   ├── lab1/task1.txt … task10.txt
    │   ├── lab2/task1.txt … task11.txt
    │   ├── lab3/task1.txt … task20.txt
    │   ├── lab4/task1.txt … task20.txt
    │   └── lab5/task1.txt … task10.txt
    ├── data/                   служебные названия и номера заданий
    ├── src/data/               исходные служебные записи
    ├── assets/                 иконки
    ├── scripts/build.mjs
    ├── tests/
    ├── package.json
    └── VERIFICATION.md
```

`data` и `src/data` содержат служебные записи о лабораторных и заданиях. Их не нужно редактировать, чтобы добавить решение. Код берётся из `solutions/*.txt`. Последний выбор задания, лабораторной, скорости и положения мини-панели сохраняется в `chrome.storage.local`; сами решения — в файлах проекта.

## Редакторы и проверка

Поддерживаются Monaco, CodeMirror 5/6, Ace, textarea и простой contenteditable. Для CodeMirror 6 и закрытых модульных экземпляров может потребоваться настройка getter в `content/adapters.js`; селекторы конкретного сайта не выдуманы. При нескольких редакторах расширение ориентируется на выбранный курсором. Если редактор неизвестен, скрыт или доступен только для чтения, ввод останавливается с сообщением.

Проверка публичной страницы AI Institute без входа показала форму авторизации и отсутствие редактора. Поэтому поведение редактора конкретного задания после входа нужно проверить на сайте. Расширение не обходит ограничения сайта.

Для запуска локальных проверок из папки `codeflow`: `npm ci`, `npx playwright install chromium`, `npm run build`, `npm test`. Браузерные тесты используют локальные страницы вместо отправки кода на сайт. Рабочие manifest содержат доступ к AI Institute для показа мини-панели.
