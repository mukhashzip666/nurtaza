## CodeFlow

Режим «Авто» в CodeFlow выполняет цикл: печать решения → RUN → ввод подготовленных значений → проверка ИИ → следующее задание. Он продолжает работу до конца библиотеки или до остановки. Подробности: [codeflow/README.md](codeflow/README.md).

Эту папку «Новая папка 6» можно выбрать в `chrome://extensions` → «Загрузить распакованное расширение». Также можно выбрать вложенную папку `codeflow`. Не перемещайте `codeflow` после установки.

Присылайте C# код заданий в этот чат по порядку. Я сохраню его в отдельные текстовые файлы проекта: для лабораторной №1, задания №1 — `codeflow/solutions/lab1/task1.txt`, для задания №2 — `task2.txt` и так далее. JSON и импорт в окне расширения не нужны.

После сохранения кода нажмите «Обновить» на карточке CodeFlow в `chrome://extensions`, откройте нужное задание на сайте и нажмите «Печать» в мини-панели сверху страницы. Подробнее: [codeflow/README.md](codeflow/README.md).

CodeFlow также открывается как обычная панель под значком расширения в Chrome. Мини-панель на сайте можно перетащить за заголовок CodeFlow; её место сохраняется. После печати следующий номер выбирается в CodeFlow автоматически; страницу следующего задания на сайте откройте сами.
